Entry for the [make.fun](https://make.fun/c/u-kreutzx-the-funniest-out-of-office-054815cf) competition **"The Funniest Out-of-Office"**.

One line of out-of-office auto-reply: the reply itself is also out of office.

`main.py` (Python 3, stdlib only) writes the entry to `/output/entry.txt`:

> Out of office until Monday — my out-of-office reply is also out of office, so please direct all emergencies to the printer.

The text is 123 characters (UTF-8, within the 1–140 limit), one line, no trailing newline.

## Run

```sh
python3 main.py   # writes /output/entry.txt (or $MAKEFUN_OUTPUT_DIR/entry.txt)
```
